# raskadrovka-book

Книга → `book.json` без текста, индекс по всему объёму, отобранные сцены с локаторами.

## Когда применять

- в проект заходит новая книга;
- нужно понять, кто в книге главный и где он описан;
- нужен список сцен, которые вообще имеет смысл рисовать.

## Главное правило: не читать книгу подряд и не читать первые главы

Первые главы — не выборка. На «Red Rising» первые три главы дают Дэрроу, Ио, Нарола и
Урода Дэна; а по всей книге главные лица — Кассий (267 упоминаний, 26 глав), Мустанг (199),
Севро (165), Титус, Пакс, Рок, Шакал. Почти все появляются после двенадцатой главы. Отбор
по началу книги промахнулся бы мимо всего состава.

Читать роман целиком дорогой моделью тоже нельзя: 670 тысяч знаков — это около 170 тысяч
токенов на один заход, и это на каждой книге.

Поэтому проход по всему тексту делает скрипт, без модели, а агент читает только окрестности
найденного.

## Процесс

### 1. Приём файла

```bash
mkdir -p books/<слаг>/source && cp <файл> books/<слаг>/source/
python3 scripts/ingest_book.py "books/<слаг>/source/<файл>" \
  --slug <слаг> --title "…" --author "…" --language en \
  --edition "…" --year 2014 \
  --rights protected --basis "автор жив, издание охраняется" \
  --numbered-only
```

Слаг — `<автор>-<название>` латиницей: `pierce-brown-red-rising`.

`--numbered-only` оставляет только пронумерованные главы, отбрасывая титул, оглавление и
колофон. Проверять вывод: если заголовки глав пустые или их подозрительно много, разбор
промахнулся — у EPUB бывает повторяющийся колонтитул и номер главы отдельным абзацем.
Тогда чинить `ingest_book.py`, а не мириться: **локаторы карточек указывают на главы, и
если нумерация съехала, съедут все ссылки на текст**.

`--rights`: `protected`, если автор жив или издание охраняется; `public-domain` — только с
обоснованием и по обоим правовым режимам, РФ и США.

В git уходит только `book.json`: выходные данные, права, оглавление и SHA-256 каждого
нормализованного абзаца. Текст остаётся в игнорируемом `cache/<слаг>/paragraphs.jsonl`.

### 2. Индекс по всей книге

```bash
python3 scripts/index_book.py <слаг> --top 20
```

Кладёт `cache/<слаг>/index.json` и печатает сводку. Что внутри:

- **`characters`** — имена собственные, ведущие себя как люди: сколько раз, в скольких
  главах, где первое упоминание и до двенадцати абзацев, где имя стоит рядом со словами про
  внешность. Именно эти абзацы потом читает `raskadrovka-characters`.
- **`places`** — имена после локативных предлогов.
- **`scenes`** — окна абзацев, набравшие балл по визуальному лексикону: свет, цвет, поза,
  движение, обстановка, материал; минус за реплики и за короткие абзацы, нормировка по длине.

Различение людей и не-людей держится на двух признаках: имя человека почти не идёт после
артикля («the House» — вещь, «Cassius» — человек) и почти не идёт после предлога места.
Шум остаётся — топонимы вроде «Mars» попадают в лица. Это нормально: агент отбрасывает их
глазами за секунду, а вот пропущенное лицо стоило бы целого прохода.

Лексиконы — `scripts/lexicon/visual_en.txt` и `visual_ru.txt`. Дополнять без опаски: лишнее
слово даёт лишнего кандидата, недостающее прячет сцену.

### 3. Чтение точечно

```bash
python3 scripts/show_paragraphs.py <слаг> --range 119 140
python3 scripts/show_paragraphs.py <слаг> --chapters 1-3 --grep "hair|eyes|face" --width 240
```

Читать только то, на что указал индекс: окрестности кандидата, абзацы описаний внешности,
главы с высокой концентрацией нужного лица.

### 4. Гейт: показать человеку

Список лиц с частотами и главами, список мест, кандидаты в сцены. Человек говорит, кого
берём в работу и какие сцены рисуем. **Не отбирать молча** — выбор героев определяет всё
дальнейшее, и он вкусовой.

### 5. Карточки сцен

Карточка — `books/<книга>/<партия>/scenes/<сцена>.json` по контракту из `books/README.md`:

```json
{
  "id": "03-ugly-dan-kidaet-kamen",
  "book": "<слаг>", "title": "…", "order": 3,
  "composition": "01-dvoe-litsom",
  "locator": {"chapter": 2, "paragraphs": [55, 57]},
  "excerpt": {"text": "…целые абзацы локатора…", "attribution": "Автор, «Название», издание, год"},
  "caption": "одна фраза для галереи",
  "brief": "что в кадре, по-русски, для людей",
  "frame": {
    "setting": "…", "time": "…",
    "characters": [{"ref": "ключ_из_библии", "state": "что делает в этом кадре"}],
    "action": "…", "mood": "…",
    "details": ["…", "…"],
    "composition": "…",
    "avoid": ["…"]
  },
  "style_refs": [], "invariants": ["ключи_из_библии"]
}
```

`frame` пишется по-английски — из него собирается промпт. `brief`, `caption` и `title` —
по-русски, они для человека.

**Детали — самая ценная часть карточки и единственная, где кадр насыщается.** Шаблон
композиции деталей не несёт по устройству, стилевой эталон не должен нести сюжета. Значит
всё, что делает кадр этой книгой, а не абстрактной сценой, лежит в `details`. Набирать их
из текста, а не из головы: «гелий-3 мерцает в жиле как жидкое серебро», «джунгли
чёрно-красных проводов по потолку пещеры», «нити биошёлка в волосах».

### 6. Проверка прав, пока нет `check.py`

- отрывок — **целые абзацы** из диапазона локатора, ничего из середины абзаца;
- не больше двух абзацев и 1500 знаков на сцену;
- сумма отрывков по книге — не больше 3% от `source.chars`;
- `attribution` непустая: автор, название, издание, год.

Посчитать сумму:

```bash
python3 -c "
import json,glob
from pathlib import Path
book=json.load(open('books/<слаг>/book.json'))
t=sum(len(json.load(open(f))['excerpt']['text']) for f in glob.glob('books/<слаг>/*/scenes/*.json'))
print(f'{t} знаков = {t/book[\"source\"][\"chars\"]*100:.2f}% (предел 3%)')"
```

## Анти-паттерны

- **Читать первые N глав и считать это выборкой.** Ради этого и написан индекс.
- **Молча выбрать героев и сцены.** Это вкусовое решение человека, не агента.
- **Отрывок из середины абзаца.** Ломает сверку по хешам, а с ней и всю проверку прав на
  чужой копии.
- **Мириться со съехавшей нумерацией глав.** Чинить разбор, а не подгонять локаторы.
- **Пустые `details`.** Кадр без деталей выйдет обобщённым, и никакая манера этого не спасёт.

## Выход

- `books/<слаг>/book.json` — в git, без текста;
- `cache/<слаг>/paragraphs.jsonl` и `index.json` — локально;
- карточки сцен в `books/<слаг>/<партия>/scenes/`;
- список лиц и сцен, показанный человеку на гейте.
