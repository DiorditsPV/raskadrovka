# Направления стиля

Манера серии не изобретается заново на каждую партию. Она берётся из направления —
папки, где манера описана словами и подкреплена свободно лицензированными референсами.
Партия выбирает направление, `add_ref.py` снимает с него копию в `input/` и переносит
записи в `metadata/refs.json` партии. Так одна и та же манера воспроизводится на разных
книгах, а провенанс каждой партии остаётся самодостаточным.

```text
styles/<направление>/
  style.json      имя, описание, формулировка для промпта, кому идёт, записи референсов
  refs/           сами изображения — только свободные лицензии
```

Слаг направления — латиницей через дефис: `sovetskaya-knizhnaya-grafika`.

## style.json

```json
{
  "slug": "sovetskaya-knizhnaya-grafika",
  "name": "Советская книжная графика 1960-х",
  "about": "Штриховая тушь с плашками двух-трёх цветов, крупная фактура бумаги, скупой цвет.",
  "style_notes_en": "ink line work with flat two-colour overlays, coarse paper grain, restrained palette of ochre, slate and brick red",
  "fits": ["классика", "реализм", "городская проза"],
  "refs": {
    "ref-01": {
      "file": "refs/ref-01.png",
      "sha256": "…",
      "source": "https://commons.wikimedia.org/wiki/File:…",
      "author": "…",
      "license": "public-domain",
      "license_basis": "автор умер в 1927 году: свободно в РФ (70 лет после смерти) и в США (публикация до 1930)",
      "why": "штрих и плашка, тёплая бумага"
    }
  }
}
```

`about` — человеку, чтобы выбрать направление глазами. `style_notes_en` — ровно та
формулировка, которая уходит в промпт в секцию Series visual language; писать её так, чтобы
она описывала палитру, рисовку и фактуру, а не сюжет. `fits` — жанры и эпохи, которым
направление идёт: по нему подбирается направление под книгу.

## Что можно класть в `refs/`

Только то, что разрешает [RIGHTS.md](../RIGHTS.md): свободная лицензия из списка
(`CC0`, `CC BY`, `CC BY-SA`, `public-domain`, `own-work`, `generated-here`), запись об
источнике и авторе и `license_basis` — обоснование свободы **и в России, и в США**.

Обложки изданий и кадры экранизаций референсами не бывают. Имена живых художников в
`style_notes_en` не называются: направление описывается тем, что видно, — линией, цветом,
фактурой, а не фамилией.

От трёх до восьми референсов на направление. Меньше трёх — манера не считывается, больше
восьми — направление перестаёт быть одним.

## Как добавить направление

1. Собрать референсы, проверить лицензию каждого по обоим правовым режимам.
2. Написать `style.json`; `sha256` каждого файла проставит `add_ref.py`, но при ручном
   заведении считается как `shasum -a 256 <файл>`.
3. `python3 scripts/check.py` — направление проходит те же проверки лицензий, что и партии.
