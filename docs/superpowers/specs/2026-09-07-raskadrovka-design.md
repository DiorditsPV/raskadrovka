# Раскадровка — замысел и контракты

Дата: 2026-09-07. Статус: принято в чате, реализуется по [плану ребилда](../plans/2026-09-07-rebuild.md).

## Цель

Из книги получить серию иллюстраций к её ключевым сценам в одной манере, заданной стилевыми
референсами, с полной историей каждой картинки: сцена, промпт, референсы, результат. Книга в
репозиторий не попадает; всё, что попадает, можно публиковать.

## Принципы

- **Дёшево.** Книгу целиком дорогой моделью не читают. Скрипты режут её на главы и абзацы и
  отбирают кандидатов в сцены эвристиками; агент в сессии смотрит только кандидатов и их
  окрестности и пишет карточки.
- **Без текста книги.** В git — манифест книги, библия, карточки сцен с отрывком не длиннее двух
  абзацев, промпты и записи о референсах. Файл книги и разбор на абзацы живут в игнорируемых папках.
- **Детерминированный промпт.** Промпт собирается скриптом из карточки, библии и записей о
  референсах и коммитится целиком. Пересборка даёт те же байты; ручные правки ловятся проверкой.
- **Provenance как в «Окрестностях».** Партия сцен — папка с `input/ prompt/ scenes/ metadata/`,
  манифест с SHA-256 всех файлов, флаг `latest`, плоский `output/`.
- **Только стандартная библиотека.** Скрипты работают на чистом Python без установки; pytest
  нужен только тестам.

## Пайплайн

1. `ingest_book.py`: FB2, EPUB, TXT → `book.json` (без текста) + `cache/<книга>/paragraphs.jsonl`.
2. `scene_candidates.py`: кандидаты в сцены по главам → `cache/<книга>/candidates.json`.
3. Агент: библия `bible.json`, карточки `scenes/<сцена>.json` по кандидатам.
4. `build_prompt.py`: карточка + библия + `refs.json` → `prompt/<сцена>.txt`.
5. Агент: генерация встроенным инструментом, один вызов на сцену, правки через edit-target.
6. `register_result.py`: PNG в `output/`, хеши и роли в `request.json`, README партии.
7. `build_gallery.py`: проверка прав, карточек, хешей и ссылок → `index.html`.

## Контракты данных

Полные образцы — в [books/README.md](../../../books/README.md). Ключевые решения:

- `book.json`: `slug`, `title`, `author`, `translator`, `language`, `edition`, `year_published`,
  `rights{status, basis, checked}`, `source{format, sha256, chars, paragraphs}`,
  `chapters[{index, title, paragraphs:[start, end)}]`. Индексы абзацев стабильны при том же
  `source.sha256`.
- `bible.json`: `characters{key: {name, appearance, appearance_en, locators[]}}`,
  `places{key: {name, look_en, locators[]}}`. Русские поля — людям, `_en` — промпту.
- Карточка сцены: `id`, `book`, `title`, `order`, `locator{chapter, paragraphs:[a, b]}`,
  `excerpt{text, attribution}`, `caption`, `brief` (по-русски), `frame` (по-английски: `setting`,
  `time`, `characters[{ref, state}]`, `action`, `mood`, `details[]`, `composition`, `avoid[]`),
  `style_refs[]`, `invariants[]`.
- `metadata/refs.json`: `{ref-id: {file, stored, sha256, source, author, license, why,
  style_notes_en}}`.
- `metadata/request.json`: `schema_version: 2`, `book`, `title`, `request`, `path_base`,
  `scenes[{id, title, order, latest, caption, card, card_sha256, prompt, prompt_sha256, output,
  output_sha256, inputs[{path, sha256, role, stored}]}]`. Роли входов: `style-reference`,
  `edit-target`.

## Шаблон промпта

По-английски, секциями, как в «Окрестностях»: Use case · Asset · Input images (роль каждого
изображения; стилевой референс отдаёт палитру, рисовку и фактуру, его сюжеты, фигуры и надписи не
переносятся) · Series visual language (из `style_notes_en`) · Scene · Characters (из библии плюс
состояние в кадре) · Action · Mood · Details · Composition · Source passage (отрывок дословно,
как контекст, не для отрисовки текста) · Identity invariants (записи библии из `invariants`) ·
Avoid (из карточки плюс постоянные: образы экранизаций, чужие иллюстрации, подписи, водяные
знаки, читаемый текст) · Final constraints.

## Права

Политика — в [RIGHTS.md](../../../RIGHTS.md). Проверяемые пределы для книг со статусом
`protected`: отрывок не длиннее двух абзацев и 1500 знаков, сумма отрывков не больше 3% объёма
книги, отрывок только из абзацев локатора. В `input/` нет текстовых файлов больше 4 КБ; под
`books/` нет файлов книг вне игнорируемой `source/`. Референс в git только со свободной
лицензией и записью об источнике.

## Родство с «Окрестностями»

Покрытие идеи родительским проектом на момент старта — около 40%.

| Слой                                | Покрытие | Что взято                                                                      |
|-------------------------------------|----------|--------------------------------------------------------------------------------|
| Приём книги и раскладка на сцены    | 0%       | ничего; вход там — бриф человека                                               |
| Отбор сцен и библия персонажей      | 10%      | паттерн identity invariants и один главный стилевой референс                   |
| Стилевые референсы и шаблон промпта | 80%      | роли изображений, запрет копировать содержимое референса, секции промпта       |
| Генерация и цикл правок             | 90%      | встроенный инструмент, один вызов на сюжет, edit-target                        |
| Хранение и provenance               | 90%      | устройство партии, манифест с SHA-256, `latest`, плоский `output/`             |
| Галерея с проверками                | 60%      | скрипт целиком; группы теперь из `book.json`, порядок сцен и подпись добавлены |
| Права и публикация                  | 50%      | схема лицензий и записи об источниках; политика по тексту новая                |

## Не делаем

Отдельный API генерации, веб-интерфейс, базу данных, полнотекстовый поиск, автоматический
подбор референсов в интернете, перевод карточек. Появится по явной просьбе.

## Гейты

- После каждой задачи: `pytest tests/` и `python3 scripts/build_gallery.py`.
- Перед публикацией первой книги: сборка без ошибок, скриншоты галереи, README с примерами.
