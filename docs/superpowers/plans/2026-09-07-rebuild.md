# Раскадровка: план ребилда из «Окрестностей»

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Довести машинерию, перенесённую из «Окрестностей», до пайплайна «книга → сцены → карточки → промпты → картинки → галерея» и прогнать первую книгу насквозь — начиная с живого кадра, а не с лесов.

**Architecture:** Скрипты на чистом Python делают черновую работу (разбор книги, снимок референсов, сборка промпта, регистрация результата, проверки), агент в сессии делает работу с суждением (библия, карточки, генерация). Всё, что коммитится, проходит проверку прав и хешей одной командой. Порядок задач подчинён одному правилу: сначала одна настоящая картинка, потом автоматизация того, что она подтвердила.

**Tech Stack:** Python 3.10+, только стандартная библиотека в `scripts/`; pytest в `tests/`; встроенный инструмент генерации изображений агента (генерация идёт через Codex-сессию пользователя).

**Spec:** `docs/superpowers/specs/2026-09-07-raskadrovka-design.md`

**Решения опросника:** «Развилки ребилда», 2026-09-07 — 20 ответов, все семь допущений приняты. Разбор, из которого выросли вопросы: `~/dev/docs/lichnoe/raskadrovka/plan-review-2026-09-07.md`.

## Global Constraints

- Скрипты в `scripts/` не тянут сторонних пакетов и не ходят в сеть. Python 3.10+ (на машине `python3` — 3.10.13).
- Один и тот же вход даёт байт-в-байт тот же выход (`book.json`, промпт, `index.html`).
- Документы и карточки по-русски; поля `_en` и промпты по-английски.
- Пределы прав для `protected`: 2 абзаца, 1500 знаков на сцену, 3% объёма книги суммарно; 4 КБ на текстовый файл в `input/`. Отрывок — целые абзацы локатора после нормализации пробелов.
- Свободные лицензии референсов: `CC0`, `CC BY`, `CC BY-SA`, `public-domain`, `own-work`, `generated-here`. У каждой записи обязателен `license_basis` — обоснование свободы и в России, и в США.
- Роли входов: `style-reference`, `character-reference`, `edit-target`. Флага `latest` в манифесте нет: правка сцены — новая партия.
- Имена: слаг книги `<автор>-<название>`, партия `NN-<имя>`, сцена `NN-<имя>`, направление стиля `<имя-латиницей>`, результат `<книга>--<партия>--<сцена>.png`.
- CI не заводим; проверка запускается командой.

import hashlib, json
import check_rights

def sha(text):
    return hashlib.sha256(check_rights.normalize(text).encode('utf-8')).hexdigest()

PARAGRAPHS = ['Первый абзац.', 'Второй абзац.', 'Третий абзац.']

def make_book(tmp_path, status='protected', chars=50000, scenes=(), refs=None, inputs=None):
    slug = 'test-book'
    batch = tmp_path / 'books' / slug / '01-batch'
    for folder in ('scenes', 'prompt', 'input', 'metadata'):
        (batch / folder).mkdir(parents=True, exist_ok=True)
    (tmp_path / 'books' / slug / 'book.json').write_text(json.dumps({
        'slug': slug, 'title': 'Книга', 'author': 'Автор',
        'rights': {'status': status, 'basis': 'проверено', 'checked': '2026-09-07'},
        'source': {'format': 'txt', 'sha256': 'x', 'chars': chars, 'paragraphs': len(PARAGRAPHS)},
        'paragraph_sha256': [sha(p) for p in PARAGRAPHS],
        'chapters': [{'index': 1, 'title': 'Глава', 'paragraphs': [0, 3]}],
    }, ensure_ascii=False))
    entries = []
    for scene in scenes:
        (batch / 'scenes' / (scene['id'] + '.json')).write_text(
            json.dumps(scene, ensure_ascii=False))
        entries.append({'id': scene['id'], 'card': 'scenes/%s.json' % scene['id'],
                        'inputs': inputs or []})
    (batch / 'metadata' / 'request.json').write_text(json.dumps({
        'schema_version': 2, 'book': slug, 'scenes': entries}, ensure_ascii=False))
    (batch / 'metadata' / 'refs.json').write_text(json.dumps(refs or {}, ensure_ascii=False))
    return tmp_path

def scene(text, paragraphs=(0, 1), scene_id='01-scene'):
    return {'id': scene_id, 'book': 'test-book', 'title': 'Сцена', 'order': 1,
            'locator': {'chapter': 1, 'paragraphs': list(paragraphs)},
            'excerpt': {'text': text, 'attribution': 'Автор, «Книга»'}}

def test_protected_rejects_three_paragraphs(tmp_path):
    root = make_book(tmp_path, scenes=[scene('\n\n'.join(PARAGRAPHS), (0, 2))])
    violations = check_rights.check_all(root)
    assert any('01-scene' in v and 'абзац' in v for v in violations)

def test_protected_rejects_long_excerpt(tmp_path):
    root = make_book(tmp_path, scenes=[scene('а' * 1600)])
    assert any('1500' in v for v in check_rights.check_all(root))

def test_protected_rejects_share_over_three_percent(tmp_path):
    root = make_book(tmp_path, chars=50000, scenes=[
        scene('а' * 1000, scene_id='01-scene'), scene('б' * 1000, scene_id='02-scene')])
    assert any('3%' in v for v in check_rights.check_all(root))

def test_public_domain_lifts_limits(tmp_path):
    root = make_book(tmp_path, status='public-domain', scenes=[scene('а' * 1600)])
    assert check_rights.check_all(root) == []

def test_book_file_outside_source_is_a_violation(tmp_path):
    root = make_book(tmp_path)
    (root / 'books' / 'test-book' / 'book.fb2').write_bytes(b'x')
    assert any('файл книги' in v for v in check_rights.check_all(root))

def test_large_text_in_input_is_a_violation(tmp_path):
    root = make_book(tmp_path)
    notes = root / 'books' / 'test-book' / '01-batch' / 'input' / 'notes.txt'
    notes.write_text('x' * 5000)
    assert any('4096' in v for v in check_rights.check_all(root))

def test_style_reference_without_refs_entry(tmp_path):
    root = make_book(tmp_path, scenes=[scene(PARAGRAPHS[0])],
                     inputs=[{'path': 'input/ref-01.png', 'role': 'style-reference',
                              'stored': True, 'sha256': 'x'}])
    assert any('refs.json' in v for v in check_rights.check_all(root))

def test_unfree_license_stored_is_a_violation(tmp_path):
    refs = {'ref-01': {'file': 'input/ref-01.png', 'stored': True,
                       'license': 'all-rights-reserved', 'source': 's', 'author': 'a'}}

                     inputs=[{'path': 'input/ref-01.png', 'role': 'style-reference',
                              'stored': True, 'sha256': 'x'}])

def test_unfree_license_not_stored_is_fine(tmp_path):
    refs = {'ref-01': {'file': 'refs-local/ref-01.png', 'stored': False,
                       'license': 'all-rights-reserved', 'source': 's', 'author': 'a'}}

                     inputs=[{'path': 'refs-local/ref-01.png', 'role': 'style-reference',
                              'stored': False, 'sha256': 'x'}])
    assert check_rights.check_all(root) == []

def test_excerpt_not_from_locator_paragraphs(tmp_path):

    assert any('локатор' in v for v in check_rights.check_all(root))

Правила разбора. FB2: только `<body>` без атрибута `name="notes"`, `<section>` рекурсивно, `<title>` секции — заголовок главы, `<p>` — абзац, `<empty-line/>` игнорируется, секция без абзацев сливается со следующей. EPUB: порядок из `spine` в OPF, XHTML в текст через `html.parser`, `h1`–`h3` — заголовок, `p` — абзац. TXT: глава начинается со строки по регулярному выражению `^(Глава|ГЛАВА|Часть|Chapter)\b|^[IVXLC]+\.?$`, иначе одна глава; абзацы по пустым строкам. Строка `paragraphs.jsonl`: `{"i": int, "chapter": int, "text": str}`. `book.json`: при существующем файле сохраняются `title`, `author`, `translator`, `edition`, `year_published`, `rights`; перезаписываются `source`, `paragraph_sha256` и `chapters`; `chapters[].paragraphs` — полуинтервал; `source.chars` — сумма длин абзацев; `paragraph_sha256[i]` — SHA-256 от `normalize(абзац_i)` в UTF-8.

def make_epub(path):
    with zipfile.ZipFile(path, 'w') as z:
        z.writestr('META-INF/container.xml',
                   '<container><rootfiles>'
                   '<rootfile full-path="OEBPS/book.opf"/>'
                   '</rootfiles></container>')
        z.writestr('OEBPS/book.opf',
                   '<package><manifest>'
                   '<item id="b" href="b.xhtml" media-type="application/xhtml+xml"/>'
                   '<item id="a" href="a.xhtml" media-type="application/xhtml+xml"/>'
                   '</manifest><spine>'
                   '<itemref idref="b"/><itemref idref="a"/>'
                   '</spine></package>')
        z.writestr('OEBPS/b.xhtml', '<html><body><h1>Вторая по алфавиту</h1><p>Абзац Б.</p></body></html>')
        z.writestr('OEBPS/a.xhtml', '<html><body><h1>Первая по алфавиту</h1><p>Абзац А.</p></body></html>')

### Task 16: Кандидаты в сцены — отложено до длинной книги

**Режим:** субагент + ревью (эвристики требуют подбора на живом тексте).

**Когда браться:** когда в работу пойдёт книга длиннее примерно 200 тысяч знаков, где читать всё целиком дорого. На книгах короче агент читает текст полностью, и эта задача не нужна.

**Files:**
- Create: `scripts/scene_candidates.py`
- Create: `scripts/lexicon/visual_ru.txt` — не меньше 120 слов, по слову в строке
- Create: `tests/test_scene_candidates.py`

**Interfaces:**

```python
def load_lexicon(path: Path) -> set[str]
def score_paragraph(text: str, lexicon: set[str]) -> float
def candidates(slug: str, root: Path, per_chapter: int = 3, window: int = 2,
               total: int | None = None) -> list[dict]
# [{"chapter": int, "paragraphs": [a, b], "score": float, "preview": str}]
```

`total` — режим «топ-N по книге», обязательный для книг с одной главой: без него `per_chapter=3` на неразбитой на главы книге даст три окна на весь текст.

Оценка абзаца: +1 за каждое слово из лексикона по началу словоформы, +2 если абзац начинается с маркера времени или места (`^(Утром|Вечером|Ночью|Днём|На другой день|Однажды|В комнате|На улице|За окном)`), −1.5 за каждую реплику (строка начинается с «—» или «–»), −1 если короче 200 знаков; итог делится на корень из длины в словах. Окно — `window` подряд идущих абзацев, балл окна — сумма; в главе берутся `per_chapter` лучших непересекающихся окон.

Лексикон, минимальная основа (дополнить до 120 слов при реализации): свет и погода — `свет, солнце, тень, сумерки, снег, дождь, туман, метель, свеча, лампа, фонарь, окно, луна, заря, мороз, ветер`; цвет — `красный, белый, чёрный, зелёный, синий, серый, золотой, багровый, бледный, тёмный, светлый, рыжий`; поза и движение — `стоял, сидел, лежал, вошёл, шёл, склонился, поднял, обернулся, замер, шагнул, опустился, протянул`; обстановка — `стол, дверь, лестница, карета, шинель, сад, улица, площадь, стена, крыша, порог, комната, зеркало, печь`.
