# Раскадровка: план ребилда из «Окрестностей»

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Довести машинерию, перенесённую из «Окрестностей», до пайплайна «книга → сцены → карточки → промпты → картинки → галерея» и прогнать первую книгу насквозь.

**Architecture:** Скрипты на чистом Python делают черновую работу (разбор книги, кандидаты в сцены, сборка промпта, регистрация результата, проверки), агент в сессии делает работу с суждением (библия, карточки, генерация). Всё, что коммитится, проходит проверку прав и хешей в одной сборке.

**Tech Stack:** Python 3.11+, только стандартная библиотека в `scripts/`; pytest в `tests/`; встроенный инструмент генерации изображений агента.

**Spec:** `docs/superpowers/specs/2026-09-07-raskadrovka-design.md`

## Global Constraints

- Скрипты в `scripts/` не тянут сторонних пакетов и не ходят в сеть.
- Один и тот же вход даёт байт-в-байт тот же выход (`book.json`, промпт, `index.html`).
- Документы и карточки по-русски; поля `_en` и промпты по-английски.
- Пределы прав для `protected`: 2 абзаца, 1500 знаков на сцену, 3% объёма книги суммарно; 4 КБ на текстовый файл в `input/`.
- Свободные лицензии референсов: `CC0`, `CC BY`, `CC BY-SA`, `public-domain`, `own-work`, `generated-here`.
- Имена: слаг книги `<автор>-<название>`, партия `NN-<имя>`, сцена `NN-<имя>`, результат `<книга>--<партия>--<сцена>.png`.

### Task 3: Приём книги

**Режим:** субагент + ревью (три парсера, форматы «в дикой природе» грязные). Донор — `github.com/DiorditsPV/book-to-anki` (`src/`, разбор FB2 и EPUB); переносить только код на стандартной библиотеке.

**Files:**
- Create: `scripts/ingest_book.py`
- Create: `tests/test_ingest_book.py` (фикстуры FB2, EPUB, TXT собираются в самом тесте: FB2 — строка XML, EPUB — `zipfile` во временной папке, TXT — строка)

**Interfaces:**
- Produces:

```python
Chapter = dict  # {"title": str, "paragraphs": list[str]}

def normalize(text: str) -> str            # схлопывает пробелы, NBSP → пробел, strip
def parse_fb2(data: bytes) -> list[Chapter]
def parse_epub(data: bytes) -> list[Chapter]
def parse_txt(text: str) -> list[Chapter]
def ingest(source: Path, slug: str, meta: dict, root: Path) -> dict
# пишет books/<slug>/book.json и cache/<slug>/paragraphs.jsonl, возвращает book.json как dict
```

CLI: `python3 scripts/ingest_book.py books/<slug>/source/<файл> --slug <slug> --title … --author … [--translator …] [--edition …] [--year 1842] --rights public-domain|protected --basis "…"`.

Правила разбора. FB2: только `<body>` без атрибута `name="notes"`, `<section>` рекурсивно, `<title>` секции — заголовок главы, `<p>` — абзац, `<empty-line/>` игнорируется, секция без абзацев сливается со следующей. EPUB: порядок из `spine` в OPF, XHTML в текст через `html.parser`, `h1`–`h3` — заголовок, `p` — абзац. TXT: глава начинается со строки по регулярному выражению `^(Глава|ГЛАВА|Часть|Chapter)\b|^[IVXLC]+\.?$`, иначе одна глава; абзацы по пустым строкам. Строка `paragraphs.jsonl`: `{"i": int, "chapter": int, "text": str}`. `book.json`: при существующем файле сохраняются `title`, `author`, `translator`, `edition`, `year_published`, `rights`; перезаписываются `source` и `chapters`; `chapters[].paragraphs` — полуинтервал; `source.chars` — сумма длин абзацев.

- [ ] **Step 1: Тесты.** FB2 с двумя секциями и заголовками → две главы, 3 и 2 абзаца, `chapters[1].paragraphs == [3, 5]`; EPUB с двумя XHTML в spine → две главы в порядке spine, не в алфавитном; TXT с «Глава 1» и «Глава 2» → две главы; NBSP и двойные пробелы схлопнуты; повторный `ingest` даёт идентичный `book.json`; существующие `rights` не затираются.
- [ ] **Step 2: Красный прогон `pytest tests/test_ingest_book.py -q`.**
- [ ] **Step 3: Реализация.** Сначала `parse_txt` и `ingest`, потом FB2 (`xml.etree`), потом EPUB (`zipfile` + `html.parser`).
- [ ] **Step 4: Зелёный прогон; ручная проверка на реальном FB2 из `books/<slug>/source/` — глав столько же, сколько в оглавлении.**
- [ ] **Step 5: Коммит «Приём книги: FB2, EPUB, TXT в book.json и кеш абзацев».**
